## 🚀 Featured Project

### 🏎️ PriceRace

**Compare. Analyze. Find the better deal.**

An AI-powered multi-provider comparison platform built to aggregate prices across **food, groceries, and rides**.

```text
Next.js + TypeScript
Node.js + Playwright
Redis + PostgreSQL / SQLite
Prometheus + Grafana
Selenium + Cloudflare
```

Currently focused on resilient provider scraping, normalization, price ranking, caching, health monitoring, and performance optimization.
